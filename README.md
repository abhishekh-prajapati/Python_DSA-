## How to Run

Clone the repository:

```bash
git clone https://github.com/abhishekh-prajapati/Python_DSA-.git
```

Move into the project directory:

```bash
cd Python_DSA-
```

Run any Python file:

```bash
python filename.py
```

Example:

```bash
python valid_anagram.py
```
